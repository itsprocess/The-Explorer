# Encounter delivery and badge sharing

Automatic challenges are resolved checks with explicit trait/item/standing causality, never invented refusal or acceptance choices. Only actual option encounters invite a decision. Camera framing excludes the player avatar without describing invisibility. Teleport timing controls belong solely to UI; the teleport dialog prioritizes its pending incident narrative over the whole tile setup.

Both profile views link badges to an opaque-token detail page. It shows existing illustration, setup, selected action when known, earned narrative and badge metadata. New choice events record the selected label; older honor badges infer it from their outcome key. Only earned outcomes are shown. Image bytes are served through an opaque badge route, with no coordinate URL or redirect. The page exposes no minimap or location link and redacts conventional coordinate pairs in prose. Missing legacy images or choices are omitted, never regenerated or invented.

Read-only sharing follows existing Sites audience access. No new AI calls, wipe or seed change. Existing canonical prose remains cached; prompting changes apply to new generation.
