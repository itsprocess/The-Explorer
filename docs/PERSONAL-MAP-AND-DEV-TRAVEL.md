# Personal mapping and Dev travel

Personal markers are keyed only by the authenticated character and cell coordinates. The server never accepts a marker owner supplied by the client. Six markers can be set or removed from the current cell, history, and public location records; public records render only the viewer's own markers through the authenticated, non-cacheable endpoint. Markers do not reveal discovery or modify world state.

The minimap uses committed visits for three states: unexplored, discovered by others, personally visited. Generated packages alone never imply discovery. Current position is highlighted independently of discovery and marker icons. New accounts receive a once-per-account welcome, acknowledged persistently.

Owner-only Dev warp stores a separate temporary character copy. It supports arbitrary in-bounds coordinates, ordinary walking, option resolution, teleport and simulated death. No visits, claims, shared imprints, discovery credit, permanent badges, deaths or distance records are awarded. Simulated items and conditions remain in the copy; exiting restores the real run. Generated scenery and image caches can be reused later by real visitors without declaring discovery. Presence broadcasts are suppressed. Every Dev action is authorized on the server.

Mystical qualities are currently interpreted through Fantasticness, with Whimsy, Chaos and Absurdity affecting tone; there is no separate Mystical field.

The owner requested a full dev wipe and new seed with this feature release. The one-time reset clears account/world data and private markers, retaining application configuration and migration history.
