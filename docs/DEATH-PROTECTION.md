# Death Protection

One non-stacking status slot: death_protection:reprieve, always single_use. Normal status gifts can grant an AI-named charge; new grants replace the occupied slot. It is displayed separately from ordinary possessions/statuses.

Only the standalone Certain Death occurrence consumes the charge to rescue the player. Return to the recorded departure tile without resolving its encounters, award no death badge, increment no deaths, and preserve other progress. The attempted move/teleport counts once; the retreat adds no move. Challenge/option kills and invalid-terrain teleport deaths are unchanged. Dev previews remain isolated from real progress.

New death narratives include a separate rescue alternative. Cached encounters use a factual rescue message with the actual protection name; no regeneration required. No polarity changes, wipe, seed change or new noise occurrence.
