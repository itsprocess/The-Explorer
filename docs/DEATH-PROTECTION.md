# Death Protection

One non-stacking status slot: death_protection:reprieve, always single_use. Normal status gifts can grant an AI-named charge; new grants replace the occupied slot. It is displayed separately from ordinary possessions/statuses.

Certain Death, direct option kills, and challenge kills (including challenges nested in options) consume the charge to rescue the player. Return to the recorded departure tile without resolving its encounters, award no death badge, increment no deaths, and preserve other progress. The attempted move/teleport counts once; the retreat adds no move. Invalid-terrain teleport deaths remain outside this protection. Rescue stops subsequent co-located encounters; one charge maximum is retained. Dev previews remain isolated from real progress.

New death narratives include a separate rescue alternative. Cached encounters use a factual rescue message with the actual protection name; no regeneration required. No polarity changes, wipe, seed change or new noise occurrence.
