# Option modal rules

Pending options use a centered native modal with blocked Escape/backdrop dismissal, focus containment, busy state and inline errors. Server movement rejects a pending option, including direct API movement requests. The selected result must resolve before travel resumes.

At most one choice in a set can lead to death. Conditional challenge outcomes and teleports count as potentially lethal. Additional potentially lethal choices become badge outcomes before their AI narrative is written. Labels describe actions without consequence warnings or spoilers.

Existing cached option packages are upgraded lazily to the revised outcome set and fresh option narratives; original terrain, images, characters, visits and world seed remain. No wipe or reset migration. No paid generation was run during verification.
