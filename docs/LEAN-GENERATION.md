# AI-authored labels and bounded generation context

No procedural biome classifier, fixed label list, or example biome descriptions are supplied. Uninterpreted cells have no prose label. Authored variable names and language poles remain the sandbox's configurable input semantics; the AI combines them into labels.

Current and adjacent uncached setting interpretations are batched into one structured call, with one shared variable-definition dictionary and compact per-cell values. Existing setting packages and cells are reused. Civil interpretation remains a distinct structured output within the batch. This replaces up to ten separate interpretation requests at an empty frontier. Canonical scenes receive the compiled interpretations without the raw ratings again; images receive scene prose, exits, traversal restrictions and population rather than the full field stack. Noteworthy variation and assigned occurrences still receive their own short interpretation. Regional identities remain cached.

A targeted five-cell fixture measured 7,296 characters for the shared setting payload against 107,808 for five complete field stacks; this is a payload-size comparison, not a measured token bill. No live paid generation was run. Actual token usage remains available through normal usage logging.
